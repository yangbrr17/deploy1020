# 从逐只建模改成通用模型

2026-10 整理。每只股票单独一个模型难维护、数据少的股票不稳。改成所有股票共用一个模型。

## 思路

- **共用一个模型，股票特征当输入：** 流动性、波动率、市值、行业、价差（以价位档计）、价位相对价格的大小等。
- **目标和特征先标准化：** 按各自波动率、成交量或盘口深度缩放，让不同股票的量纲可比。例如 OFI 除以平均深度（见 [`obi-ofi-basics.md`](obi-ofi-basics.md)）。
- **分层收缩：** 担心个股差异被抹平时，先有一个全局模型，个股只在数据足够时才偏离全局，数据少的股票自动向同类靠拢。新上市或交易稀少的股票也因此有了可用的预测。
- **维护性：** 特征、目标、训练窗口都写成配置，一套流水线跑全部股票；按股票拆开看误差，监控哪些股票长期偏离。
- **先对比再替换：** 先在原模型的评估口径上证明通用模型不比逐只建模差，再谈替换。

## 一个小实验（模拟数据）

成交量日内形状预测：个股历史有 20 天时，只用个股自己的历史最好；只有 5 天时，掺入全市场平均更好。这就是上面「数据少的股票向同类靠拢」的效果。混合权重可以按个股样本量来定（经验贝叶斯 / 混合效应模型）。

## 技术栈

| 用途 | 工具 |
|---|---|
| 数据处理 | pandas / polars |
| 主模型 | LightGBM 全局模型 |
| 对照 | statsmodels 混合效应模型 |
| 验证 | 按时间滚动验证，留 purge / embargo |
| 配置 | YAML |
| 实验记录 | MLflow |
